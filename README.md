Amigo Secreto 🎁

Este é um projeto simples para realizar sorteios de Amigo Secreto de forma prática e rápida.

📌 Funcionalidades

✅ Adicionar amigos à lista.✅ Visualizar a lista de amigos adicionados.✅ Sortear um amigo secreto de forma aleatória.✅ Exibir o amigo sorteado com um destaque em verde e fonte ampliada.✅ Reiniciar automaticamente quando novos nomes são adicionados após o sorteio.
🚀 Como Usar

1️⃣ Digite o nome de um amigo no campo de entrada e clique no botão Adicionar.2️⃣ Após adicionar todos os amigos desejados, clique no botão Sortear amigo.3️⃣ O nome sorteado será exibido na tela em verde e com fonte maior.4️⃣ Caso deseje adicionar novos amigos, a lista será reiniciada automaticamente.
